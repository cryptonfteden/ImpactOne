# Founder Install Guide — ImpactOne on Your Phone

Exact steps to install ImpactOne on your Android phone as an app, using Chrome.

## Install

1. Open **Chrome** on your phone.
2. Go to the ImpactOne web address given to you (the real deployed URL — not `localhost`, which only works on a developer's own computer).
3. Wait for the page to fully load once.
4. Tap Chrome's **⋮** menu (top right) and choose **"Install app"** (or **"Add to Home screen"** — the exact wording depends on your Chrome version).
5. Confirm the install prompt. An ImpactOne icon appears on your home screen.

## Launching

- Tap the home-screen icon, not a browser bookmark — this opens ImpactOne in its own standalone window, with no browser address bar, exactly like a native app.

## What to Expect

- **First open**: a brief load while the app fetches your real data — this is normal and identical to opening it in a desktop browser.
- **Returning to the app**: faster — the app's shell (not your financial data, which is always fetched fresh) is cached for quick reopening, and works if you briefly lose signal.
- **Rotating your phone**: the layout adapts to both portrait and landscape.
- **No signal**: the app still opens (it shows its own shell), and any screen needing live data shows an honest "unavailable" message rather than old or fake numbers.
- **An update banner appears**: this means a newer version of ImpactOne is ready. Tap **"Reload to update"** whenever it's convenient — there's no rush, and nothing breaks if you wait.

## If Something Looks Wrong

- **The install option doesn't appear in Chrome's menu**: make sure you're using Chrome (not another browser) and that you've loaded the page at least once over a real internet connection first.
- **The app opens but shows no data / an error**: this means the app couldn't reach its server — check your connection, or let whoever set this up know (this is the one thing that depends on the server being reachable from your phone, separate from the app itself).
- **You want to uninstall**: long-press the home-screen icon and remove it, exactly like any other app.

## Reporting a Problem

Note what screen you were on, what you expected, and what happened instead — that's the most useful detail for a fix.
