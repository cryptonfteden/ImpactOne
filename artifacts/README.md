# Generated and exported artifacts

This directory contains packaged evidence and generated exports rather than maintained product documentation.

- `ceo-evidence/` preserves the CEO audit and evidence directories in their original forms.
- `exports/` contains packaged deliverables such as ZIP archives.

Some CEO evidence documents are byte-identical across the preserved source directories. They remain duplicated in this pass so reorganization is separated from content deletion. A later deduplication commit may replace duplicates with a checksum manifest after explicit review.
