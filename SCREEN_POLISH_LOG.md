## Out of scope this phase (explicitly, not silently)

The ~11 legacy "IMPACTONE TERMINAL" screens (Recommendations, Daily Feed, Themes, Alerts, the old `AiAnalysisScreen.jsx`, Global Intelligence, Market Dashboard, Market Positioning, Decision Timeline) are not on the NOVA component system at all yet — "make X indistinguishable from Flagship" cannot be meaningfully asked of a screen that doesn't share Flagship's underlying components. This is the same large, already-tracked gap `CONSISTENCY_AUDIT.md` (prior phase) and `NOVA_MIGRATION.md`/`LEGACY_UI_REMAINING.md` (commit `902e4e8`, same day) both describe — real, active, incremental migration work, correctly sequenced ahead of a "cinematic polish" pass that assumes the migration is already done.

## Net result

One real, shared, root-cause CSS fix (missing transition timing on 4 core NOVA components) reaches all 7 real Workspace screens simultaneously without touching a single screen file — confirming the value of the shared-component architecture these screens were already built on. Every other checked category (glass, typography, empty/loading/error states, focus) was already consistent, having been correctly unified by prior phases (`804462e`, `3e8e498`, `DESIGN-SYSTEM-001`). Two small, real refinements (hover-shadow depth, secondary-card entrance motion) are identified and deliberately deferred as small design decisions rather than pure fixes.
