# 12 — User Flows

## New commercial user

Register → receive authenticated session → inspect plan/account → create investor profile → open Home → analyze or add symbols → create portfolio/watchlist state → receive briefs, recommendations, alerts, and explanations.

## Closed-beta user

Resolve invite code → beta context attaches to requests → use product workspaces → analytics/feedback/error events associate with beta identity. Invite codes are identifiers rather than strong credentials; this flow is separate from commercial authentication.

## Daily investor workflow

Home/morning brief → review overnight claim changes and watchlist priorities → inspect evidence and market context → open a decision or recommendation → view explanation/impact/scenario → pin, dismiss, or complete → later provide feedback and review outcomes.

## Symbol research

Search/select symbol → unified analysis invokes relevant providers/agents → committee reconciles findings → UI presents metrics, factors, risks, evidence, confidence, news, chart, impact graph, and recommendation → user saves to watchlist/workspace.

## Portfolio workflow

Select legacy or API engine → maintain positions/orders/trades/ledger → calculate performance and risk → map intelligence to holdings → create alerts and decision tasks.

## Operator workflow

Use gated health, admin, diagnostics, performance, calibration, quality, and executive dashboards → inspect provider/agent failures → adjust feature flags or methodology through authorized paths → verify with tests and audit records.
