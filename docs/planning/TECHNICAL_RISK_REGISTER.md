## Summary of unowned risks (the most important output of this register)

Two real risks (#6 dataset contamination, #10 no circuit breaker) are not covered by any of the 6 named V2 prerequisites or the 5 workstreams in `V2_EXECUTION_PLAN.md`. **These should be explicitly assigned an owner before V2 planning is considered complete** — everything else in this register already has a clear home in an existing workstream.
